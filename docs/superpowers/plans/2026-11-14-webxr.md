# 头显视角模拟、WebXR 与性能实验计划

目标：补足课程交互与实验链路，以用户无设备条件下的桌面头显视角模拟为验收项。

设计选择：沿用React/Three.js，独立模块实现姿态平滑和指标采集；原地观察，不实现瞬移、手柄或室内。模拟采用1.65米眼高、拖动目标旋转与帧率无关指数平滑；真实WebXR采用运行时姿态直接更新，不对头部做延迟滤波。入口只能由用户点击启动；退出恢复原相机及OrbitControls。模拟和真实会话输出严格区分。

优化选择：保留已有LOD、合批；比较视锥裁剪开关及缓存阴影/无阴影。固定视点、分辨率、LOD稳定状态，预热后连续渲染，记录帧间隔与提交绘制调用、三角形数。CPU提交时间不称为GPU耗时，桌面数据不称为头显FPS。

- [x] 模块与回归测试：平滑在不同帧率下收敛、角度边界、退出恢复；统计与原始样本一致。
- [x] 接入网页：模拟、复位、截图、真实XR可用性/会话退出；对XR取消桌面限帧及脏帧跳过。
- [x] 实验采集：可导出JSON、设备与视点元数据、优化开关、样本、加载状态；浏览器自动对照与截图。
- [x] 验证：新测试、既有LOD/步行测试、类型检查、构建、浏览器操作；记录失败与修正。
- [x] 交付：缺项对照、实验结果、三联图（明确模拟）、论文增补；真实设备实验和人工工时对照列为未验证。

约束：不修改其他建筑/模型哈希；不部署、不擅自提交；原始用户提示与命令输出保存在prompts_log/2026-11-14-webxr。模拟不是实际设备验证，不承诺模拟满足教师对真实头显的要求。
