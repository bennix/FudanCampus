# 西花园精修 · 第一轮：高台入口连接

2026-09-27。地点 `WTERR`；本轮仅处理入口的高低步道与楼梯连接，未完成整个西花园精修。

## 编辑约定

- 对象：西花园高台入口及其邻接东侧凹口，旧模型坐标约 X=-54…-47、Y=43…55.5。
- 原错误：两段同轴直梯无法表达实拍中的沿台步道、低位休息平台和相邻上层楼梯。
- 目标关系：入口短梯 → 沿台步道 → 第二组短梯 → 转向平台 → 相邻上层梯 → 高台。回折连接为根据连续照片提出的可复核假设，非已测定平面。
- 不变量：原场地模型、卫星固定草坪检查点、照片原名与内容不变；WTERR ID 保留。两个采光顶及花池位置、座椅和外围绿篱沿用旧版。
- 验收：原文件哈希不变；新检查点可重新打开；WTERR 网格无非流形边且有正的合计有向体积；GLB 可解析并导入 Blender；输出同相机前后斜视、俯视，以及入口人视图。

## 模型变化与限制

- 将直通入口改成三段梯（3 / 3 / 5 级）与两个高差层次；新增沿台低位步道、转向平台、侧挡墙及低花池。
- 东侧凹口随入口重做；栏杆重新沿边界布置并给平台入口留开口。
- 踏步实体向下封闭到地面；平台衔接标高为 0.42 / 0.75 / 1.23 m，全部为比例推定。
- 原铺装分格按新凹口裁切。没有新增随机拼石、树木和隐藏地下空间。
- 入口人视相机只用于关系检查，尚非经过标定的照片匹配；其左右方位未锁定，不应据此声称已与实拍完全一致。
- 高台外轮廓、尺寸、采光顶间距与校园位置仍待校正。本文件是独立局部研究，没有把旧版草坪带入新成果，也尚未和固定草坪 v2 配准。
- 网格检查不等于穷尽自交检查；栏杆与承台等构件接触处允许结构性相交。
