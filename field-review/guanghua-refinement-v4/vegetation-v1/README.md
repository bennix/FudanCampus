# 植被样区 v1 · 2026-09-29

基于 west-exit-shape-v1/view-03/west-exit-shape.blend，新建独立检查点。主参考 IMG_4568，辅助 IMG_4574。沿用植被精修计划中的东高台出口—采光顶样区；尚未推进全园替换。

## 实际修改

- 恢复此前结构审阅隐藏的 VEGETATION 组显示。before-exit 与 visibility-only-exit 区分显示设置与实际新增几何的效果。
- 新增5处分枝乔木和4组近景灌木；树冠横向展开、叶量疏密混合，保留可见枝系。树位、尺度与树种均未经过测量确认。
- 沿 ESKY、EOPEN_S、ETERR 的既有绿篱表面补细叶层，保持原种植边界和构筑物关系。
- 新增21个植物对象，分组、来源照片及随机种子可追踪；使用不透明折叠叶片网格，原始照片未改。

## 检查结果

- 原始基线文件哈希未变；所有原有网格、面索引及世界变换保持一致。新检查点重开通过。
- 新增植物顶点有效，5个新树干中心均不落在局部园路上。未做全场逐叶碰撞或自相交穷尽检查；冠叶交叠为正常植被构造。
- GLB结构有效，Blender重新导入通过，新增对象及feature_id保留。
- 网页模型加载、三个视角、新增植被显隐、390px窄屏检查通过；没有页面脚本错误。
- 查看同相机前后图、侧视图及网页截图。局部绿量与枝叶层次已有改善，但目前不能宣称达到全场照片相似度验收。

## 后续重点

照片中的成熟树干仍比本版曲折，冠层更不规则；本版枝条有程序生成的重复感。远景仍保留原球团树，尚未形成照片中的连续背景树带。近景叶片轮廓需要继续柔化，灌木表层偏齐。

本轮GLB约87.2MB，网页出口视角约231.6万三角形、584次绘制调用（含原场景）；未完成同设备前后帧时间基准，暂不作为正式校园资产替换。下一步先优化样区树枝自然度与植物网格复用，再按照片处理背景树带。

既有道路断口、高差推定与黑面仍保留，未以植物修复。相机为人工近似匹配，未测量覆盖率或达到计划中的10个百分点/5%容差。
