# 光华楼前广场精细化 v2

2026-09-30 最终续审已完成：沿用已有最终 checkpoint，仅核验铭牌并补出三张最终近景；blend 与两种 GLB 的哈希保持。详见 [最终审阅记录](final-review.md)、[模型与渲染验证](final-review-validation.json) 和 [续审网页验证](final-browser-validation.json)。铭牌无粗石穿插；牌面前置与偏暗字面仍有实景差异，已在近景中明确展示。

本轮执行完成入口修正、广场铺装、草坪路缘、驴背诗思及花钵细节。模型为照片比例重建，非测绘成果；雕像未被照片覆盖的面为简化推定。

## 完成内容

- **东入口**：原园地北缘位于模型 y=87，中央草坪东端位于 y≈77.854，造成突出端头。本轮将入口两侧边缘齐头，双花钵关于 x≈65.444 对称，中心间距7，前后位置和高度一致。主草坪原平面网格保持。园路退至花钵后方接直路，旧支路伸入直路的部分裁齐。
- **围栏楼梯口**：为配合新的园地边界，北侧楼梯口整体向园内退6个模型单位，尺寸不缩放；原地面孔洞回填、新位置重新开洞。关联绿篱与踏步一起调整，冲突的小灌木移到旁边。绝对位移属于布局推定。
- **花钵**：东侧重做宽口浅盆、竖肋、盆沿、基座压顶与石材面板缝，补红花和宽叶；西侧花钵位置保持。
- **铺装**：广场使用浅色大分格带、灰色石板细缝、板间低反差色差与石材细颗粒；弧线边缘由几何裁切，不覆盖草坪。补楼前窄排水线。
- **草坪边缘**：移除原连续细白线，沿既有草坪轮廓建立分段石沿、窄缝、小倒角与少量边缘草叶；新入口及雕像绿地也有石材收边。
- **驴背诗思**：楼前西侧绿地新增独立地标 POET_DONKEY。包含低头驴、四肢和蹄、耳朵与尾部、骑者帽子和衣袍、缰绳、铸造底部、分层石砌基座、粗面石块、压顶和“驢背詩思”铭牌；补局部绿地、乔木、灌木和景石背景。雕像外观为暗灰绿金属和有限氧化色差。

## 复现

在仓库根目录用已有 Blender 运行 `build.py -- --build-only`，然后运行 `finalize.py`。`repair_plaque.py`是最终图发现粗石面擦入铭牌后的局部修订脚本；该修订已经写回 build.py，重新从头生成不需要重复运行。程序使用固定随机种子；原照片和旧检查点均保留。

对照过程中修复了植物局部移动导致的拉伸、曲径伸入直路、铭牌与粗石面的交叠。此前遗留、位于东高台深处的园路大形与本轮广场不是同一精修范围；不以本次检查声称整个校园均已完成照片复原。
