# 西入口齐头修复 v3

文字导出已修正：独立 GLB 补回两处“光华楼广场自行车库”与 FUDAN，审阅页新增三个文字近景。原始 Blender 文件不变；修正后的大小、哈希、重新导入及实际浏览器截图见 [车库文字导出修复](../garage-text-export/README.md)。下文模型大小及旧验证文件为文字修复前记录。

本版完成西入口端头、花钵、楼梯口及园路连接的修复。来源为 `../forecourt-v2/forecourt-complete-v2.blend` 和本目录的 `diagnostic-west-entry.blend`；两份来源保留，源文件哈希写入 `validation.json`。

## 交付

- `west-entry-aligned-v3.blend`：完整可编辑场景。
- `west-entry-aligned-v3.glb`：完整独立导出，53 张纹理嵌入。
- `review.html`：载入最终 GLB，提供西入口、正面、俯视、园路接缝、东西同框、东入口、全园七个视角，以及树叶开关。
- 六张 `after-*.png`：1600 × 1200、Cycles 48 采样，含与修改前相同机位的斜视。接缝近景隐藏树叶便于检查。
- `validation.json`：模型、源文件、闭合网格、地面探测、GLB 及渲染记录。
- `browser-validation.json`：网页实际载入、视角、图片、窄屏及控制检查。

## 修复结果

西侧直路北端与入口端线对齐到 y=77.854482。西侧花钵中心为 (−30.5,79.064482) 和 (−23.5,79.064482)，围绕 x=−27 的中线对称；中心距 7，与东侧花钵同一前后线。西侧直接复用东侧组件，网格、材质和高度一致。

西北楼梯口、绿篱、踏石沿 y 移动 −9.145518。父子层级仅移动根节点，独立叶片皮肤另移动一次；逐个核对世界变换。旧孔回填到完整地面深度，并入地面网格；新孔与楼梯匹配。

新园路与旧曲径在 y=75 共用切口顶点，路面和底部路缘分别形成闭合网格，没有独立重叠连接片。y<74.99 的旧曲径顶点保持。地面射线核验旧孔已填、新孔开通，园路截面与连接中心线表面连续。拐点的一张长椅沿 x 移动 −2.1 至草地，避免遮挡通路；同网格内其它长椅顶点保持。

982 个未涉及本轮的网格几何、拓扑和世界变换摘要与来源一致；中央草坪原曲线、东入口、雕像、东西高台及其它楼梯口沿用。地面、广场和两条园路实体均为闭合、正体积网格。叶片为原有开放片网格，不按实体封闭要求验收。

GLB 约 200.9 MB，相比来源增加约 0.08%。保留可选择的语义组件及 feature_id；未通过合并整座场景来减小文件。导出解析、纹理嵌入及 Blender 重新导入通过，最终 blend 重开并再次核对受保护对象。

## 依据和边界

主参考为 IMG_4491（宽口花钵）；IMG_4469、IMG_4492 辅助入口与园路关系。端头对齐是用户确认的目标，具体尺寸、退让距离和曲线连接为布局推定，未作为现场测量数据。中央草坪原本不严格镜像，本版保留其轮廓。

本交付为完整独立审阅模型。旧 `forecourt-v2/review.html` 增加新版入口，当前审阅页展示本版 GLB。校园正式清单、其它建筑及既有未提交改动保留。

## 复现

使用仓库已有 Blender 4.4.3 运行 `finalize_west.py`：打开来源和诊断场景、修复接缝及长椅、核验、保存新文件、导出、渲染并重新导入。该脚本不重建东入口或草坪。`check_browser.cjs` 提供可选的浏览器验证脚本；本轮网页通过应用浏览器实际检查。静态审阅页以仓库根目录为服务根，可在本地 8772 端口打开。
