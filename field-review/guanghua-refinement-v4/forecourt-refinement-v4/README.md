## 修改与核验

**01 楼前入口与连续挡墙**：重建平台、中央台阶、两侧坡道及弧形种植坛；挡墙、压顶与圆花钵底座连续接合。 坡道末端与平台同为推定标高 3.45；花钵底与压顶同为 0.915；修改实体闭合且体积为正。

**02 东入口花钵盆足与压顶**：扩大盆足、降低细颈并减薄压顶；盆足平面坐落在石顶；先分离与西花钵共享的数据。 盆足底与压顶同为推定标高 0.92；东侧两盆独立，西花钵几何保持。

**03 直通道铺装与凹槽边带**：中间通道改为独立矩形错缝铺装；两边拆出 198 个独立边带实体及浅弧槽。 中心宽约 2.94、边带宽 0.33、槽深 0.06 均为推定；修改实体通过闭合与正体积检查。

**04 曲径黑三角与纹理黑楔形**：合并四段道路上表面、去除重叠面与北端折返面，清理两个退化面；替换旧纹理中的重复黑楔形。 去除约 8.10 平方单位重复投影面积；曲径非流形边 0、零面积面 0、正体积 33.959；新贴图已打包。

**05 广场分格与入口铺装**：独立广场材质统一浅色大分格、细板缝和入口坡面纹理方向，保持广场边界。 大分格 6、小板 1.2 × 1.5、浅带 0.18 均为推定；本阶段全部网格几何保持。

六份检查点已通过重开及必要 feature_id 检查，本次核对 SHA-256 全部一致。受保护的 631 个主草坪、西入口等网格及楼体主体顶点/拓扑保持；来源文件校验值保持。见 [重开验证](final-validation.json)。

最终文件重新打开后，252 个之前通过阶段实体检查的修改对象再次全部通过：非流形边 0、零面积面 0、正体积、坐标有限。曲径使用独立清洁石材纹理，广场使用独立校准纹理，两项纹理均已打包；曲径贴图无 RGB 最大通道低于 0.05 的黑像素。贴图统计与交汇近景共同支持黑楔形残留已处理。见 [收尾审计](delivery-audit.json) 和 [交汇前后近景](final-review.html#stage04)。
