# 化学楼第二轮：用户指定砖色 #D46B57

用户已认可第一轮形状和细节，本轮只校正砖色并要求 git add/commit。正式几何、窗户和三处门廊保持第一轮形状。

旧版备份在 `web-integration-backup`，修改前视图在 `renders/before-*`，本轮视图在 `renders/after-*`。`verify_color.py` 直接解码GLB嵌入PNG，要求90%以上砖面像素接近sRGB(212,107,87)，砖面中位数准确等于用户色值，同时检查所有几何accessor缓冲和节点/网格结构不变。

上一轮实际导出PNG砖色约#56180D：将较小浮点颜色值直接写入sRGB图片，导致砖面比预期更暗。本轮纹理按用户sRGB值生成，保留±2/255颗粒与少量砖缝；无贴图时的材质常量则使用sRGB转线性后的值。网页光照、阴影和色调映射会继续影响屏幕观感，#D46B57为砖面底色而非所有屏幕像素。

本轮沿用Blender4.4.3，仅生成buildings-55 LOD；更新manifest/hash、必要步行资源，验证非55建筑和LOD保持不变。原始提示词、命令输出、问题修复和验证记录在 `prompts_log/2026-11-14-chemistry-v2`。两轮内容一并本地提交，不推送。
