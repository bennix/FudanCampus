# 西花园高台 v3 · 采光顶露出关系与照片材质

2026-09-27。承接 v2；用户要求继续精修，同时将材质与照片大致对齐。

## 本轮约定与结果

- 对象：WTERR 两个采光顶、主平台与入口铺装、木栏、花池、座椅和绿篱。
- 原误差：采光顶基座与玻璃露出过高；平台是单一黄灰面，木栏过浅，缺少实拍中的灰／粉灰拼石与深灰分格。
- 目标：玻璃下沿藏于绿篱后，尖顶略高于绿篱；按照片调整材质的主色、颗粒感和粗糙度。
- 不变量：v2、固定草坪 v2 和原照片不改；沿用入口连接假设及平台轮廓、双采光顶平面位置，不把树冠下无法确认的卫星边界当成实测。
- 比较：相同镜头、光线的 before/after-overview 和 before/after-platform；after-entry 为入口材质检查。

卫星图复核后，西花园仍有大量树冠遮挡，无法可靠锁定整个高台边界。本轮保留其推定状态；照片材质按用户要求先做整体对齐，可随后续结构调整继续使用。

## 交付和验证

- `west-garden-terrace-v3.blend`：可编辑模型，贴图已打包。
- `west-garden-terrace-v3.glb`：模型与贴图内嵌导出，玻璃使用 glTF transmission。
- `review.html`：交互模型、同视角对照和照片参考。通过项目根目录的本地 HTTP 服务打开。
- `validation.json`：原版本哈希、重新打开、闭合与正体积检查、GLB 导入及内嵌贴图检查。
- `preview-validation.json`：浏览器加载、带贴图网格与页面错误检查。

材质图片由脚本生成，不是实拍裁切或逐像素颜色标定。未补造隐藏地下结构，也未并入校园正式资产。不同查看器的环境光会影响玻璃反射和颜色。

下一目标：继续利用连续地面照片确认入口方位与高台整体尺度，然后将该局部与固定草坪边界配准。
